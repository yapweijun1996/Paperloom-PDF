# Reporting a security issue

Please do not include private PDFs, credentials, signing keys, or other sensitive
information in a public issue. If private vulnerability reporting is enabled for
this repository, use its GitHub Security tab to report the issue privately.
Otherwise, contact the repository maintainer through an existing private channel
before sharing sensitive details. The availability of private reporting and a
response timetable have not been verified.

When reporting, describe the affected version, impact, and steps using a small
synthetic example. Keep any real documents or credentials under your control.
